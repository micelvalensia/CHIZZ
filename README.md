# 🧀 Chizz - Fake Cheese Product Landing Page (React.js)

**Chizz** adalah sebuah landing page satu halaman bertema keju palsu (fake product) yang dibangun menggunakan **React.js**. Website ini menampilkan informasi seputar produk Chizz dalam layout modern dan responsif.

## 📄 Deskripsi

Landing page ini dibuat untuk kebutuhan showcase UI/UX dengan konten fiktif. Meskipun produknya tidak nyata, desain dan strukturnya meniru landing page sederhana, lengkap dengan beberapa section:

## 🧩 Halaman

- **Home** – Tampilan utama pengenalan brand.
- **About** – Informasi singkat tentang latar belakang Chizz.
- **Product** – Showcase produk Chizz.
- **Contact** – Formulir atau info kontak pengunjung.

## ⚙️ Teknologi yang Digunakan

- **React.js** – Library utama untuk membangun UI.
- **Vite** – untuk build tool dan environment.
- **TailwindCSS** – Untuk styling.
- **Responsive Design** – Layout fleksibel di semua ukuran layar.

## 🚀 Cara Menjalankan

1. Clone repo:
   ```bash
   git clone https://github.com/micelvalensia/WebsiteEc.git
   cd WebsiteEc
   npm install
   npm run dev
   ```
Buka browser di http://localhost:5173
